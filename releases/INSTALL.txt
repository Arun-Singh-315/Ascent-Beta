# Ascent Android Installation Guide

Android 7.0 (API level 24) or newer is required.

1. Build or download the latest release APK.
2. Transfer or open the APK on your Android device.
3. If prompted, grant permission to "Install unknown apps" from the file manager or browser.
4. Tap Install to install or update Ascent.
5. Launch Ascent and complete initialization.
6. Grant Notification and Exact Alarm permissions when prompted to enable scheduled reminders and study timers.

For existing users:
Updating over the existing app preserves all local data, database records, and settings.
Always export a workspace backup from Settings -> Workspace Backup before major OS upgrades or manual re-installs.
