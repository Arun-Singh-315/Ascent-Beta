ASCENT 1.0.8 — Android beta

Share Ascent-1.0.8-9.apk with users. Android 7.0 or newer is required.

1. Download the APK onto your Android phone.
2. Open it. If Android asks, allow installation from the app used to open the file.
3. Tap Install, then open Ascent and complete setup.
4. Allow notification access when you want reminders. Quiet is the default; enable “Ring as an alarm” per reminder and follow its access prompts for ringing alerts.

Existing Ascent users: install over the existing app to retain data. If Android reports a signature conflict, export a workspace backup before considering removal of the older app.

This release-mode universal APK uses the existing development signing certificate for compatibility with the installed beta. A dedicated release key is still needed for store distribution.
